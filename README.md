# Condor booth PC: setup

One-time setup for remote admin access on the Condor booth mini PC.

1. Download [main.zip](https://github.com/condorsecurity-it/condor-booth-display/archive/refs/heads/main.zip).
2. Right-click the zip → **Properties** → tick **Unblock** → OK, then extract it.
3. Open `enroll`, double-click `Enroll-Booth-PC.cmd` and click **Yes** on the admin prompt.
4. When it shows a green SUMMARY, install NetBird and sign in.
